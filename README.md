# Ejercicio de Maquetación - Mockup de Mastermind 🛠️

Este repositorio contiene un proyecto de práctica desarrollado durante el curso de HTML y CSS de la academia Mastermind. Consiste en la maquetación de un mockup proporcionado en clase para aplicar los conocimientos teóricos adquiridos.

## 🎯 Objetivo del Proyecto
El propósito de este código es puramente educativo. No es un portafolio profesional ni un producto final, sino un ejercicio de aprendizaje para entender cómo interactúan HTML y CSS en la construcción de una interfaz web estática.

## 💻 Tecnologías Aplicadas
- **HTML5:** Estructura de la página, anidación de etiquetas y maquetación del contenido.
- **CSS3:** Estilos básicos, uso de clases, identificadores, colores, tipografías y modelo de caja.

## 🧠 Conceptos Practicados
- **De visual a código:** Traducción de un mockup estático a código funcional en el navegador.
- **Estructura y Estilos:** Mantenimiento de la separación lógica entre el contenido (HTML) y la presentación (CSS).
- **Multimedia:** Inserción y control de elementos de video nativos de HTML5.
- **Módulos:** Práctica de maquetación en bloques específicos, como la estructura de una firma de correo.
